# Mr. Khan Burger House — Website

A 3-page static website (Home, Menu, About) built with plain HTML5, CSS3, and
vanilla JavaScript — no frameworks, no build step. Open `index.html` in a
browser, or upload the whole `project/` folder to any static host.

## Structure

```
index.html          Home page (hero, speciality, why-choose-us, testimonials, CTA)
menu.html            Menu page (search, categories, cart, WhatsApp checkout)
about.html           About page (story, gallery + lightbox, map, contact)
sitemap.xml
robots.txt

assets/
  images/            General site imagery
  gallery/            About-page gallery photos
  speciality/         "Our Speciality" section photos
  testimonials/        Customer photos (optional — slider currently uses initials)
  menu/                Per-item menu photos — file names referenced from data/menu.json
  logos/               Mr. Khan + VisionXSystems logos
  icons/                Any extra icons/favicons

data/
  menu.json            All menu items, prices, categories — edit this to update the menu

res/
  mrkhan.css            All styling (no inline CSS anywhere)
  mrkhan.js             Cart, checkout, menu loader, gallery, nav, animations

vendor/                Reserved for any third-party libraries you add later
```

## Replacing placeholder images

Every image on the site is currently a placeholder generated by
`https://placehold.co` so nothing is broken while real photography is not
yet available. To swap in real photos:

1. Drop the real file into the matching `assets/...` folder using a similar
   name (e.g. `assets/menu/zinger-burger.jpg`).
2. For menu items, edit the `img` field for that item in `data/menu.json` to
   point at the new file, e.g. `"img": "assets/menu/zinger-burger.jpg"`.
3. For the hero, speciality, gallery, and about images, just replace the
   `src="https://placehold.co/..."` attribute in `index.html` / `about.html`
   with the new local path.

If an image referenced in `menu.json` fails to load, the menu page
automatically falls back to a branded placeholder — the site never shows a
broken image icon.

## Editing the menu

Everything on the Menu page is generated from `data/menu.json`. Add, remove,
or edit items there — no HTML editing required. Each item needs:

```json
{
  "id": 29,
  "name": "New Item",
  "category": "originals",
  "desc": "Short description.",
  "price": 300,
  "img": "assets/menu/new-item.jpg"
}
```

Category ids must match one of the entries in the `categories` array at the
top of the file.

## Cart & WhatsApp checkout

The cart is stored in the browser's LocalStorage (key `mrkhan_cart_v1`) so it
survives page refreshes and carries across all three pages. Checkout only
supports Cash on Delivery. On "Send Order via WhatsApp", the site builds a
formatted order message, URL-encodes it, and opens
`https://wa.me/923169264990?text=...` in a new tab.

## Notes / assumptions

- Domain used in SEO tags (`https://mrkhanburgerhouse.com`) is a placeholder —
  update `<link rel="canonical">`, Open Graph, Twitter Card, `sitemap.xml`,
  and `robots.txt` once a real domain is live.
- Opening hours are placeholders throughout, as requested.
- The Google Maps embed on the About page uses an address-based query (no API
  key required). Swap it for an exact place embed once you have the full
  Google Maps place link.
